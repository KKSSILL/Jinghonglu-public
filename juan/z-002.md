# 官家亲自画娘

<sub>Windows 7 时代起　·　微软日本及授权方</sub><br>
<code>前史</code> <code>官方下场</code>

</div>

---

网友画得热闹，微软也坐不住了。日本出 Windows 7 旗舰版的时候，随盘附赠一位名叫窗边七七（Madobe Nanami）的姑娘，头七千七百七十七套里送壁纸和音效，配音请的是水树奈奈。

后来 Windows 8、10 也各有“窗边”家的姑娘，官方认下的 OS 娘，前后有好几位。

<table><tr><td>

**异史氏曰**　民间戏称，官家照单全收，这是极少见的事。惟独 Windows 11 没有官娘，只有网友自画的一位，还得自己凑合着认。
